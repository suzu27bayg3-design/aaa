```
量子アニーリングは、1998年に東京工業大学の門脇正史さんと西森秀稔さんが提案した、日本生まれの量子計算の方法です。
たくさんの選び方から一番よい答えを探す「組合せ最適化」を、量子のゆらぎで解こうとするしくみと、D-Waveの装置、そして「本当に速いのか？」という議論まで、ずんだもんと四国めたんが約5分で解説します。

・組合せ最適化：30都市の道順は約4.4×10^30通り（1秒に1兆通り調べても約1400億年）
・答えを地形に置きかえ、一番低い谷を探す
・焼きなまし（アニーリング）から量子アニーリングへ
・D-Waveの装置（2011年発表、2025年 Advantage2 は4400量子ビット超）
・ゲート型とのちがいと、速さをめぐる議論
・量子に着想を得た、ふつうの計算機（富士通 デジタルアニーラ）
```
