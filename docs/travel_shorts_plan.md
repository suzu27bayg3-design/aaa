# 「ふしぎな絶景の科学」ショート 企画案（日本編）

奇妙な観光地・自然遺産を、写真（ゆっくりズーム・横に流す）と「なぜこうなるのか」の動く図で紹介する縦長ショート。
1本30〜40秒。最後に「行ってみたい？」で終わり、コメントを集める。

## 1本の流れ（共通）

| 時間 | 画面 | 内容 |
|---|---|---|
| 0〜3秒 | 一番インパクトのある写真を全面に＋大きな問いかけ | 「この六角形の柱、人が作ったと思う？」 |
| 3〜8秒 | 日本地図に場所のピンが落ちる | 「正解は兵庫県・玄武洞。自然にできたもの」 |
| 8〜25秒 | 原理の動く図（写真と交互） | 「溶岩が冷えて縮むとき、六角形に割れる」 |
| 25〜33秒 | 写真＋おまけの驚き | 「しかもここで、地球の磁石の逆転が見つかった」 |
| 33〜38秒 | 冒頭の写真に戻る（ループ） | 「行ってみたい？コメントで！」 |

- 写真は Wikimedia Commons の自由なライセンスのもの（CC BY / CC BY-SA / パブリックドメイン）だけを使い、撮影者とライセンスを画面の隅と説明欄に書く
- 声と立ち絵（ずんだもん・めたん）は、使うかどうか選べる（ナレーションだけにもできる）

## 1本目のおすすめ：玄武洞

- 見た目で一瞬で引きつけられる（自然にできた六角形の柱）
- 原理（冷えて縮む → 六角形に割れる）が、動く図でわかりやすい
- 「地球の磁石の逆転を世界で初めて見つけた場所」という、科学のおまけ話がある
  - 京都帝国大学の松山基範が、玄武洞の玄武岩が今の地磁気と逆向きに磁化していることを示した（発見は1926年、発表は1929年とする資料がある）
  - 約260万〜78万年前の逆転期は「松山逆転期」と呼ばれる（資料により約70万年前とも）
- 山陰海岸ジオパークの中心で、2023年に「世界の地質遺産100選」に選ばれたと報じられている
