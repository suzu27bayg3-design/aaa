# ショート動画の説明文テンプレート（伸びやすい形）

## 基本の考え方
- ショートは主にフィードで再生されるため、説明文は「**検索で見つけてもらう**」「**開いた人を次の行動へ**」の2つのために書く
- 説明欄は最初の数行しか見られない → **1〜2行目に検索キーワード＋フック**を入れる
- 中身は「保存したくなる**まとめ**」にする（数字を箇条書き）
- 誘導は1つずつ：**コメント（2択の質問）**と**シリーズの別動画**
- ハッシュタグは**3〜5個**。60個を超えると全部無視される（YouTube公式）
- 誤解を招く書き方・関係ないキーワードの詰め込みはしない（規約違反・評価低下のおそれ）

## テンプレート
```
【1行目：検索されやすい言葉＋フック】（例：大谷翔平／イチロー＋選手名＋「成績」）
2行目：答えの一部と「何がすごいか」を1文で（数字を1〜2個）

▼〇〇 成績まとめ
・通算：…
・特徴的な記録：…
・タイトル：…
・最も輝いた年（〇〇年）：…

💬 2択の質問（コメント誘導）
▶ シリーズ名：他の選手名 も公開中

※数字の注記（資料による差など）
出典：…
写真：…
音声：VOICEVOX:ずんだもん

#ハッシュタグ3〜5個（日本語の検索語を優先）
```

## キーワードの選び方
- 日本の視聴者が検索する言葉を優先：「メジャーリーグ」「MLB」「大谷翔平」「イチロー」、選手名のカタカナ表記
- 選手名は表記ゆれも意識（例：ゲーリッグ／ゲーリック）。説明文の中で1回だけ自然に併記する
