# 「ふしぎな絶景の科学」ショートの作り方の決まり

## 流れ
1. テーマ確認（毎日 11:47 ごろ）：候補を1〜2個と、場面ごとの流れ（表）を送り、OKをもらう
2. 作成（毎日 18:51 ごろ、19時に届くように）：OKをもらったテーマだけ作る。OKがなければ作らず、短く知らせる
3. 長さは60〜80秒まで。シリーズ名「ふしぎな絶景の科学」、声はずんだもんと四国めたん

## 見せ方（ユーザーの指示）
- **ダサい図（色を塗っただけの四角・三角・線の図）を使った説明はしない**
- 使うもの：
  - 本物の航空写真・昔の航空写真（国土地理院の地理院タイル）、地質図（産総研シームレス地質図）
  - Wikimedia Commons の自由ライセンスの写真（CC0 / CC BY / CC BY-SA。NC・NDは使わない）
  - 航空写真の上の演出（光る粒の流れ、光る輪、範囲をふわっと光らせる、昔と今の切りかえ）
- 仕組みの説明は、本物の景色の上で動きを見せる。どうしても図が要るときは、写真や地図の上に重ねる
- 日本地図のピンは、国土地理院の航空写真でのズーム（`tools/geo_area.py` → show=("zoom",)）

## 正確さ
- 公的機関・大学・論文で確かめた事実だけを言う。説が分かれるものは「考えられている」「伝説」と言い、メモに残す
- 演出（光る粒の道すじなど）が目安であることは、metadata.md のメモに書く

## 道具
- `tools/geo_area.py`：ズーム用の航空写真と、地質図の範囲
- `tools/gsi_tiles.py`：地理院タイル（photo / std / relief / hillshade / geology、昔の写真 ort_old10 / gazo1）
- `tools/travel_short.py`：動画と metadata.md の書き出し
- 写真：Commons の幅500px版（大きいサイズは Commons の自動取得制限で取れない）
