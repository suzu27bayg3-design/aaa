## 素材について（重要）
- **試合映像・プレー動画は使っていません。** MLBの映像は権利管理が厳しく、無断で使うと著作権侵害の申し立て（削除・ストライク）の対象になります。
- **写真も使っていません。** 1920年代以前に出版された写真には米国でパブリックドメインのものもありますが、写真ごとに権利状況の確認が必要です。使う場合は Wikimedia Commons や米国議会図書館（LOC）でライセンス表示を確認したものだけにしてください。
- 成績（数字）は事実なので自由に使えます。映像は図・数字アニメーションで構成しています。
