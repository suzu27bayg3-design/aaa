# YouTube の成績分析

`tools/yt_analyze.py` で、YouTube Studio から書き出したデータを分析し、動画ごとの成績と改善の候補をレポートにする。

## 1. データの書き出し方（YouTube Studio・パソコンのブラウザ）
1. YouTube Studio を開き、左のメニューから「アナリティクス」を選ぶ
2. 右上の「詳細モード」を開く
3. 上のタブで「コンテンツ」（動画ごとの表）を選び、期間を「全期間」など分析したい範囲にする
4. 列の「＋」から、次の指標を追加する（無い列は分析を省く）
   - 視聴回数、総再生時間、平均視聴時間、平均再生率
   - インプレッション数、インプレッションのクリック率
   - チャンネル登録者、高評価
5. 右上の「エクスポート」（下向き矢印）→「カンマ区切り値 (.csv)」でZIPを保存する
6. そのZIPを、GitHubのこのリポジトリの `analysis/` フォルダにアップロードする（スマホのGitHubアプリやブラウザの「Add file → Upload files」）

※スマホのYouTube Studioアプリには書き出し機能が無いため、パソコン（またはスマホのブラウザでデスクトップ表示）で行う。
※ZIPには視聴回数などの数字だけが入り、パスワードや個人情報は入らない。

## 2. 分析の実行
```
python3 tools/yt_analyze.py analysis/<書き出したZIP> -o analysis/report
```
`analysis/report.html`（グラフと表）と `analysis/report.md`（要点）ができる。

## 3. 見ている指標と基本の原理
| 段階 | 指標 | 低いときに直すところ |
|---|---|---|
| 見つけてもらう | インプレッション数 | タイトルの検索語・投稿の頻度・シリーズのつながり |
| クリックしてもらう | インプレッションのクリック率 | サムネイルとタイトル |
| 見続けてもらう | 平均再生率・平均視聴時間 | 冒頭の数秒・構成・テンポ |
| ファンになってもらう | 1000回再生あたりの登録者・高評価 | 終わり方・シリーズへの誘導・固定コメント |

- **漏斗（ろうと）の考え方**: 視聴回数 ≒ インプレッション × クリック率。どの段階で人数が減っているかを見れば、直す場所が分かる。
- **偶然のぶれ**: クリック率のような割合は、母数が少ないと偶然で大きく変わる。レポートでは95%信頼区間（Wilson の方法）を付け、区間が中央値から外れたときだけ「差がある」と判断する。
- **ショートと通常動画は別々に比べる**: ショートはフィードで自動的に流れることが多く、クリック率よりも平均再生率と登録への効果を重視する。
