# 立ち絵素材
- `zundamon/` : ずんだもん（坂本アヒル「ずんだもん立ち絵素材」 ニコニコ静画 im10788496 の見本画像から切り出し）
  - happy.png（笑顔）/ smug.png（ドヤ顔）/ shy.png（照れ）/ panic.png（焦り）
- `metan/` : 四国めたん（坂本アヒル「四国めたん立ち絵素材」 ニコニコ静画 im10791276 の見本画像から切り出し）
  - normal.png
- `preview_*.jpg` は元の見本画像

※見本画像は低解像度で、口・目のパーツが分かれていないため、口パクの代わりに「声に合わせて弾む」演出にしている。
素材本体（PSD）から同じファイル名のPNGを書き出して差し替えれば、`tools/longform.py` がそのまま使う。
利用条件は各素材の規約と東北ずん子プロジェクトのガイドライン（https://zunko.jp/guideline.html）に従うこと。
