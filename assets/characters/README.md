# 立ち絵素材

坂本アヒルさんの立ち絵素材（PSD）から、`tools/psd_parts.py` で書き出したもの。
- ずんだもん立ち絵素材 2.3（`ずんだもん立ち絵素材.zip`）
- 四国めたん立ち絵素材 2.1（`四国めたん立ち絵素材.zip`）

## ファイル名
`<表情>__<目><口>.png`
- 目: `o` = 開き / `c` = 閉じ（まばたき用）
- 口: `0` = 閉じ / `1` = 半開き / `2` = 開き（声の大きさで切り替える口パク用）
- 表情
  - ずんだもん: happy / smug（腰に手）/ shy（照れ）/ panic（焦り・汗）/ think（考える）
  - 四国めたん: happy / explain（指差し）/ smug（口元に指）/ shy / panic

## しくみ（PSDToolの約束事）
PSDの層名の先頭が「`*`」なら、同じグループ内で1つだけ表示する選択肢（目・口・腕など）。
「`!`」で始まるグループは常に表示する。`psd_parts.py` はこの約束に従って層の表示を切り替え、合成して書き出す。
表情を足したいときは `psd_parts.py` の `CHARS[...]["expr"]` に層のパスを追加して再実行する。

```
python3 tools/psd_parts.py "<ずんだもん立ち絵素材2.3.psd>" "<四国めたん立ち絵素材2.1.psd>"
```
