# 科学の雑学ショート テーマ候補

毎日の予約（夜9時）は、この表の上から順に、前日と違う分野になるように選ぶ。
使ったら「済」に日付を入れる。1本ごとに「なぜそうなるか（原理）」を必ず説明する。
数字や主張は、作るときに論文・大学・公的機関・百科事典で確かめ直す（ここに書いたのはまだ確認前の見出し）。
