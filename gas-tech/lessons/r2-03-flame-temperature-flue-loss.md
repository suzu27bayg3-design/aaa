# 第 2 周 第 03 回 燃焼計算の深掘り：エネルギー収支から断熱火炎温度と排ガス損失を導く

**分野：基礎理論（第 03 回の応用）**

## ねらい
- 第 03 回の物質収支（原子は消えない）に、第 05 回の熱力学第一法則を組み合わせ、**断熱火炎温度**を自分で計算できる。
- 空気比 λ を上げると火炎温度が下がる理由を、「同じ発熱で温める相手が増える」という収支で説明できる。
- 排ガス分析計が表示する**排ガス損失**（ジーゲルト式）が、同じエネルギー収支の別の使い方であることを確かめられる。

## 1. 原理編

### 1.1 記号と前提
| 記号 | 意味 | 単位 |
|------|------|------|
| λ | 空気比（実際の空気量 / 理論空気量） | 無次元 |
| n_i | 燃料 1 mol あたりの生成物 i の物質量 | mol |
| H_i(T) − H_i(298) | 生成物 i の顕熱エンタルピー | kJ/mol |
| LHV | 低位発熱量（生成した水は水蒸気のまま） | kJ/mol |
| T_ad | 断熱火炎温度 | K |

前提は次のとおりです。
- 定圧で燃焼する。
- 燃料と空気は 25 °C（298 K）で供給する。
- 外部への熱損失はない（断熱）。
- 燃焼は完全燃焼とし、解離は考えない（解離の影響は 1.4 で扱う）。
- 空気の組成は O₂ : N₂ = 1 : 3.76 とする。

### 1.2 物質収支（第 03 回の復習）
メタンを空気比 λ で燃やすと、反応式は次のようになります。

  CH₄ + 2λ(O₂ + 3.76N₂) → CO₂ + 2H₂O + 2(λ−1)O₂ + 7.52λN₂

### 1.3 エネルギー収支 → 断熱火炎温度
定圧・断熱では、反応物のエンタルピーと生成物のエンタルピーが等しくなります（第一法則）。
反応物を 298 K で供給するとき、この条件は次のように書けます。

  **Σ n_i [H_i(T_ad) − H_i(298)] = LHV**

意味は「燃焼で出た熱（LHV）が、すべて生成ガスの温度上昇に使われる」ということです。
- 左辺は T_ad について単調に増えます。そのため二分法で解けます。
- 比熱は温度とともに大きくなるので、「LHV ÷（平均比熱 × 物質量）」の 1 回の割り算では精度が足りません。温度の関数としてエンタルピーを積分します（ここでは NIST の Shomate 式を使いました）。
- **λ が大きいと T_ad が下がる理由**：右辺の発熱量は λ によって変わりません。一方、左辺では温めるべき相手（余分な O₂ と N₂）が増えます。同じ熱を多くのガスで分け合うので、温度は下がります。

LHV を使う理由は、生成した水が水蒸気のまま火炎の中にあるためです（凝縮しないので、凝縮潜熱は出ません。第 24 回）。

### 1.4 実際の火炎温度は解離で下がる
2000 K を超えると、CO₂ → CO + ½O₂ や H₂O → H₂ + ½O₂ のような**解離**（吸熱反応）が起こります。その分だけ火炎温度が下がります。
NASA CEA と GRI-Mech 3.0 を使った計算では、メタン-空気の量論燃焼での断熱火炎温度は次のとおりです（[Marzouk, arXiv:2503.11826](https://arxiv.org/abs/2503.11826)）。
- 完全燃焼の仮定：**2326.35 K**
- 化学平衡（解離を含む）：**2224.25 K**

炭化水素燃料と空気の定圧断熱火炎温度は、どれもおよそ 1950 °C 前後に集まり、メタン-空気は 1963 °C とされています（[Adiabatic flame temperature - Wikipedia](https://en.wikipedia.org/wiki/Adiabatic_flame_temperature)）。

### 1.5 同じ収支を排ガスに使う → 排ガス損失
機器から出た排ガスは、燃焼用空気より高い温度で出ていきます。その差の分だけ、熱が捨てられることになります。

  排ガス損失 q_A = Σ n_i [H_i(t_A) − H_i(t_L)] / LHV

（t_A：排ガス温度、t_L：燃焼用空気の温度）

比熱をほぼ一定とみなし、「排ガスの量は λ に比例し、λ は O₂ 濃度から 21/(21−O₂) で求まる」（第 03 回 1.5）を使うと、上の式は次の簡単な形になります。これが**ジーゲルト（Siegert）式**です。

  **q_A = (t_A − t_L) · [A₂/(21 − O₂) + B]**（O₂ を測る形）
  **q_A = (t_A − t_L) · [A₁/CO₂ + B]**（CO₂ を測る形）

天然ガスの係数は A₁ = 0.37、A₂ = 0.66、B = 0.009 です（[haustechnikdialog「Abgasverlust」](https://www.haustechnikdialog.de/SHKwissen/94/Abgasverlust)）。
排ガス分析計（Testo）も、O₂ を測る形を A₂ = 0.66、B = 0.009 で使っています（[Testo 330-1 取扱説明書（manualslib）](https://www.manualslib.com/manual/1454338/Testo-330-1.html?page=54)、[Testo 300 取扱説明書（manualslib）](https://www.manualslib.com/manual/2309172/Testo-300-M-I.html?page=56)）。

## 2. 実務とのつながり
- **NOx と空気比**：火炎温度が高いほど、サーマル NOx が増えます。希薄予混合燃焼（λ を大きくする）や排ガス再循環が NOx 対策になるのは、1.3 の「温める相手を増やして T_ad を下げる」という仕組みを使っているからです。
- **効率と空気比**：λ を大きくしすぎると、排ガスの量が増えて損失 q_A が増えます。λ を小さくしすぎると、不完全燃焼で CO が出ます（第 22 回）。このため、排ガスの O₂ を測りながら空気比を調整します。
- **排ガス分析計の表示**：分析計は O₂ と温度を測って、ジーゲルト式で q_A を計算し、「燃焼効率 ≒ 100 − q_A」と表示します。係数は燃料ごとに設定するので、燃料の選択を間違えると表示値もずれます。
- **潜熱回収型の機器**：ジーゲルト式は顕熱だけを扱っています。凝縮型の機器では、凝縮で回収した分の補正が別に必要です（[Testo 300 取扱説明書](https://www.manualslib.com/manual/2309172/Testo-300-M-I.html?page=56)、第 24 回）。

## 3. 計算例（python で検算済み）

前提：
- メタンの LHV は 802.3 kJ/mol とします。
- エンタルピーは NIST Shomate 式の係数で計算しました。
  ※ このセッションでは NIST WebBook にアクセスできなかったため、係数は既知の値を使いました。
  その妥当性は、次のように確認しています。
  - 各物質で 298 K のときの H − H(298) ≒ 0 になる（±0.005 kJ/mol 以内）。
  - λ = 1 の結果が、上の arXiv 論文の完全燃焼の値と一致する。

### 計算例 1：空気比と断熱火炎温度（完全燃焼の仮定）
| λ | T_ad [K] | T_ad [°C] |
|---|---------|-----------|
| 1.0 | **2327** | 2054 |
| 1.1 | 2189 | 1916 |
| 1.2 | 2070 | 1796 |
| 1.3 | 1965 | 1691 |
| 1.5 | 1789 | 1516 |
| 2.0 | 1481 | 1208 |

- λ = 1 の 2327 K は、論文の完全燃焼の値 2326.35 K と一致しました。計算方法とデータが正しいことの確認になります。
- 実際には解離が起こるので、量論付近では約 100 K 低くなります（論文の平衡値は 2224 K）。
- λ を 1.0 から 1.3 にすると、T_ad は約 360 K 下がります。

### 計算例 2：排ガス損失（λ = 1.2、排ガス 150 °C、燃焼用空気 20 °C）
- 乾き排ガス中の O₂：2(λ−1) / [1 + 2(λ−1) + 7.52λ] = **3.84 %**
- 乾き排ガス中の CO₂：1 / [1 + 0.4 + 9.024] = **9.59 %**

| 計算方法 | q_A |
|---------|-----|
| エンタルピー収支を直接計算（LHV 基準） | **6.20 %** |
| ジーゲルト式（O₂、A₂ = 0.66）：130 × (0.66/17.16 + 0.009) | 6.17 % |
| ジーゲルト式（CO₂、A₁ = 0.37）：130 × (0.37/9.59 + 0.009) | 6.19 % |

3 つの方法がほぼ一致します。ジーゲルト式が「エネルギー収支の近似」であることが確かめられます。

注意：A₁ = 0.37 を O₂ を測る形に代入すると、130 × (0.37/17.16 + 0.009) = 3.97 % となり、**約 2/3 に過小評価**します。係数 A₁ と A₂ は使う形が違います。

## 4. 理解確認

### 理解確認 1（なぜ）
空気比を 1.0 から 1.3 に上げると、断熱火炎温度は約 360 K 下がる。発熱量は変わらないのに温度が下がる理由を、エネルギー収支の式で説明せよ。
<details><summary>解答</summary>

収支式 Σn_i[H_i(T_ad) − H_i(298)] = LHV で、右辺は λ によらず一定である。λ を上げると、左辺の n_O₂ = 2(λ−1) と n_N₂ = 7.52λ が増える。同じ熱量を、より多くの物質量で分け合うことになるので、到達温度 T_ad は下がる。
</details>

### 理解確認 2（計算）
ある機器で、排ガス温度 180 °C、燃焼用空気 20 °C、乾き排ガス中の O₂ 5.0 % だった。天然ガスのジーゲルト式（A₂ = 0.66、B = 0.009）で排ガス損失を求めよ。
<details><summary>解答</summary>

手順：q_A = 160 × (0.66/16 + 0.009) = 160 × (0.04125 + 0.009) = 160 × 0.05025 = **8.0 %**。燃焼効率はおよそ 92 %。
</details>

### 理解確認 3（誤っているものはどれか）
1. (イ) 断熱火炎温度の計算に LHV を使うのは、火炎の中で生成した水が水蒸気のままだからである。
2. (ロ) 完全燃焼を仮定して計算した断熱火炎温度は、解離を考えた実際の値より低くなる。
3. (ハ) ジーゲルト式は、排ガスの顕熱損失を、空気比が O₂ 濃度で決まることを使って近似したものである。

<details><summary>解答</summary>

誤りは **(ロ)**。解離は吸熱反応なので、解離を考えると温度は**下がる**。完全燃焼を仮定した値（2326 K）は、平衡を考えた値（2224 K）より**高い**。
</details>

## 5. よくある誤解・ひっかけ
- **平均比熱で 1 回だけ割る**：比熱は温度とともに大きくなるので、高温では T_ad を高く見積もりがちです。エンタルピーを温度の関数として積分します。
- **HHV を使う**：火炎の中で水は凝縮しないので、T_ad の計算には LHV を使います。
- **A₁ と A₂ の取り違え**：CO₂ を測る形には A₁、O₂ を測る形には A₂ を使います。代入を間違えると、損失を大きく見誤ります（計算例 2）。
