# 第 2 周 第 07 回 流体力学の深掘り：圧縮性流れとチョーク（臨界流）

**分野：基礎理論（第 07 回の応用）**

## ねらい
- 定常流れのエネルギー式（h₀ = h + v²/2）と等エントロピーの関係から、**ノズルを通る質量流束**の式を導ける。
- 質量流束が最大になる条件から、**臨界圧力比** p*/p₀ = [2/(γ+1)]^{γ/(γ−1)} と「のどの部分で流速が音速になる」ことを導ける。
- チョーク流れでは、流量が下流の圧力に関係なく上流の圧力に比例する理由を説明し、中圧導管の漏えい量を見積もれる。

## 1. 原理編

### 1.1 記号と前提
| 記号 | 意味 | 単位 |
|------|------|------|
| p₀, T₀, ρ₀ | 上流のよどみ点（容器内）の圧力・温度・密度 | Pa, K, kg/m³ |
| p_b | 下流（背圧） | Pa |
| p* | のど（最も細い部分）の臨界圧力 | Pa |
| γ | 比熱比 | 無次元 |
| R | 比気体定数 = 8.314/M | J/(kg·K) |
| A | 穴（のど）の面積 | m² |
| C | 流出係数 | 無次元 |
| ṁ | 質量流量 | kg/s |

前提は次のとおりです。
- 理想気体とし、比熱は一定とする。
- 断熱・可逆（等エントロピー）の流れとする。
- 上流は十分広く、流速はゼロとみなす（よどみ点）。

### 1.2 第 07 回との違い
第 07 回のオリフィスの式は、密度を一定とみなした（非圧縮）ベルヌーイの式から出発しました。そのため、気体には膨張補正係数 ε を掛けて補正していました。
今回は、密度の変化を最初から式に入れます。差圧が大きいときに何が起こるかを見るためです。

### 1.3 導出 1：質量流束の式
定常流れのエネルギー式は、よどみ点のエンタルピー h₀ が流れに沿って保存されることを表します。

  h₀ = h + v²/2 → v = √[2c_p(T₀ − T)]

等エントロピー変化なので、T/T₀ = (p/p₀)^{(γ−1)/γ}、ρ/ρ₀ = (p/p₀)^{1/γ} です。圧力比を π = p/p₀ とおいて質量流束 G = ρv を求めると、次のようになります。

  **G = √{ 2ρ₀p₀ · γ/(γ−1) · [π^{2/γ} − π^{(γ+1)/γ}] }**

π = 1（差圧なし）では G = 0 です。π を下げていくと G は増えます。ところが π → 0 でも、括弧の中は 0 に戻ります。つまり、**G には最大値があります。**

### 1.4 導出 2：臨界圧力比とチョーク
括弧の中を π で微分して 0 とおくと、次の式が得られます。

  **π* = p*/p₀ = [2/(γ+1)]^{γ/(γ−1)}**

このときの流速は、その場所の音速 a = √(γRT) とちょうど等しくなります（マッハ数 1）。
- 空気（γ = 1.4）：π* = **0.528**
- メタン（γ = 1.31）：π* = **0.544**

（臨界条件と式：[Wikipedia: Choked flow](https://en.wikipedia.org/wiki/Choked_flow)。メタンの γ = 1.31：[Engineering ToolBox: Methane](https://engineeringtoolbox.com/methane-d_1420.html)、比熱比の一覧：[Engineering ToolBox: Specific heat ratio](https://www.engineeringtoolbox.com/specific-heat-ratio-d_608.html)）

背圧 p_b を p* より下げても、のどの圧力は p* のまま変わらず、流量は増えません。これが**チョーク（臨界流）**です。
理由は、下流の圧力の変化が圧力波（音速で伝わる）として上流に伝わろうとしても、のどでは流れが音速なので、それより上流に伝わらないためです。

チョーク流れの質量流量は、次の式で表されます。

  **ṁ = C·A·p₀ · √[γ/(RT₀)] · [2/(γ+1)]^{(γ+1)/[2(γ−1)]}**

- **ṁ は p₀ に比例**し、p_b を含みません。
- 上流の温度 T₀ が高いと、ṁ は √T₀ に反比例して小さくなります。

チョークが起こる条件は、上流と下流の絶対圧の比が [(γ+1)/2]^{γ/(γ−1)} 以上になることです（[eng-tips FAQ](https://www.eng-tips.com/faqs.cfm?fid=1201)）。
単純な薄いオリフィスでは、チョークさせるのに 44〜53 % の圧力降下が必要だという記述もあります（[米国特許 US11306840（PDF）](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/11306840)）。

## 2. 実務とのつながり
- **漏えい量の見積もり**：中圧以上（ゲージ圧で約 0.08 MPa 以上）の導管にあいた穴からの漏えいは、チョーク流れになります。漏えい量は穴の面積と上流の絶対圧に比例します。非圧縮の式を使うと過大に見積もってしまいます（計算例 2）。
- **安全弁・逃し弁の容量計算**：多くの場合、臨界流の式で吹出し量を求めます。吹出し量が背圧によらないので、容量を決めやすくなります。
- **臨界ノズル流量計**：チョークさせると、流量は上流の圧力と温度だけで決まります。この性質を使って、流量計の校正の基準に使われます。
- **低圧の供給（ゲージ圧 2 kPa）**：圧力比は約 0.98 なので、圧縮性はほとんど効きません。第 07 回の非圧縮の式で十分です。

## 3. 計算例（python で検算済み）

前提：メタン（γ = 1.31、R = 518.3 J/(kg·K)）、T₀ = 288.15 K、大気圧 101.325 kPa、穴の直径 1 mm、C = 1 とします。
体積の換算には、標準状態（0 °C、1 atm）の密度 0.716 kg/m³N を使います。

### 計算例 1：臨界条件
| 量 | 空気 γ = 1.4 | メタン γ = 1.31 |
|----|-------------|---------------|
| p*/p₀ | 0.528 | 0.544 |
| T*/T₀ = 2/(γ+1) | 0.833 | 0.866 |

メタンの場合、上流の絶対圧が 101.325/0.544 = **186 kPa**（ゲージ圧で約 85 kPa）を超えると、大気への漏えいはチョークします。
のどでのメタンの音速は a* ≒ 412 m/s です。

### 計算例 2：直径 1 mm の穴からの漏えい量
| ゲージ圧 | チョーク | 圧縮性を考えた式 [m³N/h] | 非圧縮の式 [m³N/h] | 非圧縮 ÷ 圧縮性 |
|---------|---------|-------------------|-----------------|------------|
| 2 kPa | なし | 0.206 | 0.208 | 1.01 |
| 50 kPa | なし | 0.996 | 1.258 | 1.26 |
| 0.1 MPa | あり | 1.377 | 2.051 | 1.49 |
| 0.3 MPa | あり | 2.745 | 5.016 | 1.83 |
| 1.0 MPa | あり | 7.533 | 15.17 | 2.01 |

- 低圧では、両方の式がほぼ一致します（差は 1 %）。
- 圧力が高くなるほど、非圧縮の式は過大になり、1 MPa では約 2 倍になります。
- チョーク域では、漏えい量は絶対圧にほぼ比例します。たとえば 0.3 → 1.0 MPa（ゲージ圧）では、絶対圧の比 1101/401 = 2.74 で、流量の比 7.53/2.75 = 2.74 と一致します。

## 4. 理解確認

### 理解確認 1（なぜ）
チョークした流れで、下流の圧力をさらに下げても流量が増えないのはなぜか。「圧力の情報が伝わる速さ」に着目して説明せよ。
<details><summary>解答</summary>

圧力の変化は、圧力波として音速で伝わる。チョークしたのどでは、流れの速さが音速に等しい。そのため、下流で圧力を下げても、その変化はのどより上流に伝わらない。

上流側の流れは下流の変化を「知らない」ので、のどの状態（p*、T*）も質量流量も変わらない。
</details>

### 理解確認 2（計算）
メタンが入った容器（絶対圧 0.5 MPa、15 °C）に直径 2 mm の穴があき、大気中に漏れた。C = 0.8 として、漏えい量 [kg/s] を求めよ。
<details><summary>解答</summary>

手順：
- 0.101/0.5 = 0.20 < 0.544 なのでチョークしている。
- 式：ṁ = C·A·p₀·√[γ/(RT₀)]·[2/(γ+1)]^{(γ+1)/[2(γ−1)]}
- A = π/4 × (0.002)² = 3.14 × 10⁻⁶ m²
- √[1.31/(518.3 × 288.15)] = 2.962 × 10⁻³ s/m
- [2/2.31]^{3.725} = 0.585

したがって、ṁ = 0.8 × 3.14×10⁻⁶ × 5×10⁵ × 2.962×10⁻³ × 0.585 ≒ **2.2 × 10⁻³ kg/s**（約 11 m³N/h）。
</details>

### 理解確認 3（誤っているものはどれか）
1. (イ) メタンの臨界圧力比は約 0.54 である。上流の絶対圧が大気圧の約 1.84 倍を超えると、大気への噴出はチョークする。
2. (ロ) チョーク流れの質量流量は、上流と下流の圧力差の平方根に比例する。
3. (ハ) 低圧（ゲージ圧 2 kPa）のガスの漏えいでは、非圧縮のベルヌーイの式で十分に見積もれる。

<details><summary>解答</summary>

誤りは **(ロ)**。チョーク流れの質量流量は、**上流の絶対圧 p₀ に比例**し、下流の圧力には関係しない。差圧の平方根に比例するのは、非圧縮の場合（第 07 回のオリフィスの式）である。
</details>

## 5. よくある誤解・ひっかけ
- **ゲージ圧と絶対圧の混同**：臨界圧力比の判定にも、チョーク流量の式にも絶対圧を使います。
- **「穴の出口の速さは音速を超えない」**：単純な穴（先が細くなるだけのノズル）ではそのとおりです。末広ノズル（ラバルノズル）では、のどより下流で超音速になります。
- **C の値**：実際の穴やすき間では、縮流や摩擦のため C < 1 になります。安全側の見積もりをするときは、目的に合わせて C を選びます（漏えい量を多めに見積もりたいなら C を大きめにとる）。
