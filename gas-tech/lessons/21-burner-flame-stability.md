# 第 21 回 バーナと炎の安定性

**分野：ガス技術（消費）**

## ねらい
- ブンゼン式バーナが一次空気を吸い込む仕組みを、ベルヌーイの式と運動量の保存から説明できる。
- 吸い込む空気の割合が、ガスの流量によらず、ノズルの面積比とガスの密度で決まることを導ける。
- 逆火とリフト（浮き上がり）が起こる条件を、混合気の流速と燃焼速度のつり合い、および壁近くの速度勾配から説明できる。

## 1. 原理編

### 1.1 一次空気の吸い込み（エゼクタの原理）
ブンゼン式バーナでは、ノズルからガスを勢いよく噴き出させ、そのまわりの一次空気口から空気を吸い込み、混合管の中で混ぜてから炎口に送ります。
- ガスの噴流が混合管の細いところ（スロート）を通ると速度が上がり、ベルヌーイの式（第 07 回）のとおり静圧が大気圧より下がる。この圧力差で一次空気が吸い込まれ、炎口に着く前にガスと混ざる（[BCcampus Open Textbook：Describe atmospheric burners](https://opentextbc.ca/plumbing3e/chapter/describe-atmospheric-burners/)）。
- 一次空気の割合は、理論空気量の 30〜60 % 程度とされる（[米国特許 4135875](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/4135875)、[BCcampus](https://opentextbc.ca/plumbing3e/chapter/describe-atmospheric-burners/)）。足りない空気は、炎のまわりから二次空気として取り込まれる。
- 炎は、内側の淡い青色の一次炎（小さな円すい）と、外側のほぼ無色の二次炎に分かれる。二次炎は、残った燃料がまわりの空気と反応してできる（[Britannica：Bunsen burner](https://www.britannica.com/print/article/84759)）。

### 1.2 吸い込む空気の割合を導く（運動量の保存）
ノズルを出たガスの運動量が、混合管の中で吸い込んだ空気に分け与えられる、と考えます。圧力の効果と摩擦を無視した理想化したモデルです（教材としての導出）。

- 運動量の保存：ρ_g·A_g·v_g² = ρ_m·A_m·v_m²
- 体積流量：Q_g = A_g·v_g（ガス）、Q_m = A_m·v_m（混合気）

これを整理すると、

  **Q_m / Q_g = √( (ρ_g / ρ_m) · (A_m / A_g) )**

吸い込む空気の体積はQ_a = Q_m − Q_g なので、空気とガスの比（一次空気比）は

  **r = Q_a / Q_g = √( (ρ_g / ρ_m) · (A_m / A_g) ) − 1**

| 記号 | 意味 |
|------|------|
| A_g, A_m | ノズルの面積、混合管（スロート）の面積 |
| ρ_g, ρ_m | ガスの密度、混合気の密度 |
| v_g, v_m | ガスの噴出速度、混合気の速度 |

**大事な性質**：式にガスの流量（v_g）が入っていません。つまり、火力を絞ってガスを減らしても、**一次空気の割合はほぼ一定**に保たれます。ガスが減ると吸い込む力も同じ割合で減るからです。

一方で、式にはガスの密度 ρ_g が入っています。ガスの種類が変わると一次空気の割合が変わり、炎の状態も変わります。これが、ガスの互換性をウォッベ指数だけでなく燃焼速度でも見る理由の 1 つです（第 01 回、第 04 回）。

### 1.3 炎がその場にとどまる条件
炎口から出る混合気の速さを u、層流燃焼速度を S_L とすると（第 04 回）、
- **u ≈ S_L のどこか**で炎の面がつり合い、炎が炎口にとどまる。
- **u < S_L**（流れが遅すぎる）：炎が混合管の中へ戻る＝**逆火**。
- **u ≫ S_L**（流れが速すぎる）：炎が炎口から浮き上がり、ついには吹き消える＝**リフト、吹き消え**。

（[米国特許 4135875](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/4135875)、[米国特許 9062879（インショットバーナ）](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/9062879)）

- 火力を大きくしすぎると炎が浮き上がって不安定になり、騒音や CO が増える。火力を小さくしすぎると逆火が起こりやすい（[米国特許 9062879](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/9062879)）。
- 混合気の温度が上がると燃焼速度が上がり、逆火の原因になる（[米国特許 4135875](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/4135875)）。
- 一次空気が多すぎると、小さく硬い青い炎になったり、炎口から吹き飛んだり、ノズルの方へ逆火したりする。そのときは空気口を絞る（[BCcampus](https://opentextbc.ca/plumbing3e/chapter/describe-atmospheric-burners/)）。
- 逆に空気が少なすぎると、燃え切らない炭素の粒（すす）が熱で光り、炎が黄色くなる（イエローチップ）（[MEL Science：Bunsen burner flame test](https://melscience.com/CA-en/articles/bunsen-burner-flame-test/)）。

### 1.4 壁の近くの速度勾配（臨界速度勾配）
管の中の流れは、壁でほぼ 0、中心で最大の速さです。壁の近くでは流れが遅いので、炎はまずここから戻ろうとします。ルイスとフォン・エルベは、壁での**速度勾配**（壁から離れるにつれて速さがどれだけ増えるか）が、ある臨界値より小さいと逆火が起こる、という考え方を示しました。臨界値は、燃焼速度を消炎距離（壁が熱を奪って炎が近づけない距離）で割った大きさで表されます（[NASA 技術報告](https://ntrs.nasa.gov/api/citations/19930084721/downloads/19930084721.pdf)、[MDPI Energies 2023](https://mdpi.com/1996-1073/16/4/1844)）。

円管の層流（放物線分布。第 08 回）では、壁での速度勾配は **g = 8·V̄ / D**（V̄：平均流速、D：内径）です。同じ平均流速なら、**炎口が小さいほど速度勾配が大きく**、逆火しにくくなります（計算例 2）。

## 2. 実務とのつながり
- **ガスコンロ・給湯器のバーナ**：小さな炎口をたくさん並べるのは、壁の速度勾配を大きくし、消炎距離の効果も使って逆火を防ぐため。
- **ガスの種類が変わるとき**：熱量変更（転換）でノズルを交換するのは、入熱（ウォッベ指数）と一次空気の割合を合わせ直すためである（第 01 回）。
- **水素の混入**：水素は燃焼速度が速いので（第 04 回）、逆火しやすくなる。密度も小さいので、一次空気の割合も変わる（計算例 1）。
- **不完全燃焼（第 22 回）**：一次空気が足りない、炎が冷たい物に触れる、などで CO が出る。

## 3. 計算例
（python で検算済み。1.2 の理想化した式を使い、混合気の密度は空気とガスの体積加重平均として繰り返し計算した）

**例 1：一次空気比と、ガスの密度の影響**
理論空気量は、メタンの値 9.52（体積比。第 03 回）で比べる。
| 面積比 A_m/A_g | ガスの比重（空気 = 1） | 一次空気比 r | 理論空気量に対する割合 |
|---------------|------------------|-------------|------------------|
| 50 | 0.64 | 4.8 | 約 51 % |
| 50 | 0.55 | 4.5 | 約 47 % |
| 50 | 0.45 | 4.0 | 約 42 % |
| 100 | 0.64 | 7.2 | 約 75 % |
- ガスが軽くなる（水素を混ぜるなど）と、吸い込む空気の割合は下がる。
- 面積比を大きくすると、一次空気は増える。
- どの場合も、ガスの流量を変えても r は変わらない。

**例 2：炎口の大きさと壁の速度勾配**
平均流速 1.0 m/s のとき、g = 8V̄/D は、
- 内径 4 mm：**2,000 1/s**
- 内径 2 mm：**4,000 1/s**
炎口を小さくすると、壁の速度勾配が 2 倍になり、逆火しにくくなる。

## 4. 理解確認

### 理解確認 1
ブンゼン式バーナで火力を絞っても、一次空気の割合がほぼ変わらないのはなぜか。

<details><summary>解答</summary>

空気を吸い込む力はガスの噴流の運動量から来ていて、ガスを減らすと、吸い込む空気も同じ割合で減るから。運動量の保存から求めた一次空気比 r = √((ρ_g/ρ_m)(A_m/A_g)) − 1 には、ガスの流量が入っていない。
</details>

### 理解確認 2
火力を小さくしすぎると逆火、大きくしすぎるとリフトが起こるのはなぜか。

<details><summary>解答</summary>

炎は、混合気の流速と燃焼速度がつり合う所にとどまる。火力を絞ると流速が燃焼速度より遅くなり、炎が上流（混合管の中）へ進んで逆火する。火力を上げすぎると流速が燃焼速度よりずっと速くなり、炎が押し流されて炎口から浮き上がり、吹き消える。
</details>

### 理解確認 3（誤っているものはどれか）
(a) 炎口を小さくすると、同じ平均流速でも壁の速度勾配が大きくなり、逆火しにくくなる。
(b) 一次空気が不足すると、すすが光って炎が黄色くなる。
(c) ブンゼン式バーナの一次空気の割合は、ガスの密度に関係なく、ノズルの形だけで決まる。

<details><summary>解答</summary>

誤りは **(c)**。一次空気比は、面積比だけでなくガスの密度にもよる（例 1）。ガスの種類が変わると一次空気の割合も変わるので、ノズルの交換などで調整し直す必要がある。
</details>
