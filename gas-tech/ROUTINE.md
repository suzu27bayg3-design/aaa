# 日次ルーチン（スケジュール実行用の手順）

1. `PROGRESS.md` を読み、最初の未完了テーマを選ぶ。
2. `lessons/NN-<slug>.md` を作成する。構成は必ず:
   1. **ねらい**（3 行以内）
   2. **基礎原理**：式は導出から書く。単位と前提条件を明記
   3. **応用・実務**：設備・保安・法令との接点
   4. **計算例**（数値を入れて一つ解く）
   5. **確認問題**（3 問、解答は `<details>` で折りたたむ）
   6. **参考文献**：本文の主張ごとに出典を付け、すべて機能するハイパーリンクにする。
      Web 検索・取得で実在を確認した URL だけを使う。公的機関・学会・事業者の一次資料を優先。
3. `PROGRESS.md` のチェックを付け、日付とファイルへのリンクを記入する。
4. コミットしてプッシュする。
