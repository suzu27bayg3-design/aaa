# 日次ルーチン

1. `PROGRESS.md` を読み、次の 2 本を選ぶ（同時並行）。
   - **技術トラック**：01〜26 のうち最初の未完了テーマ（すべて終わっていたら第 2 周）
   - **法令トラック**：27〜34 のうち最初の未完了テーマ（すべて終わっていたら法令の演習編 L-NN）
2. 2 本それぞれについて `lessons/NN-<slug>.md` を作成する。分野によって構成が違う。

## 基礎理論・ガス技術（01〜26）：原理の理解だけ。試験対策はしない
1. **ねらい**（3 行以内）
2. **原理編**：核になる原理を、基本法則（保存則・状態方程式など）から導く。
   式ごとに記号の意味・単位・前提を書く。「なぜその式の形になるか」を言葉でも説明する。
3. **実務とのつながり**：設備・保安でどう使われるか。
4. **計算例**：数値を入れて 1〜2 問解く。手順も書く。
5. **理解確認**：「なぜ」を問う問題を 3 問。解答は `<details>` で折りたたむ。
   試験の出題形式に合わせる必要はない。
6. **参考文献**

## 法令（27〜34）：試験対策
1. **ねらい**と、対象となる法律・政省令の条文番号
2. **条文の趣旨**：その規定が何を防ぐためにあるか。保安上の理由と結びつけて説明する。
3. **要点の整理**：義務の主体（誰が）・対象・期限・届出先などを表にする。
4. **試験編**：正誤問題 5 問（「誤っているものはどれか」形式）と、穴埋め問題 2 問。
   解答と解説は `<details>` で折りたたむ。解説では根拠の条文を示す。
5. **ひっかけポイント**（2〜3 個）：主体の取り違え、「届出」と「許可」、期限の違いなど。
6. **参考文献**：条文は e-Gov 法令検索のリンクを付ける。
   ガス事業法（昭和29年法律第51号）は https://laws.e-gov.go.jp/law/329AC0000000051 。
   e-Gov に接続できないときは、経済産業省の資料などで条文番号を確かめ、その旨をノートに書く。
   法令は改正されるので、確認した日付と、最後の改正（例：令和4年法律第80号）をノートに書く。

## 共通
- 参考文献：本文の主張ごとに出典を付け、すべて機能するハイパーリンクにする。
  WebSearch / WebFetch で実在を確認した URL だけを使う。公的機関・学会・事業者の一次資料を優先する。
- 計算は python で検算する。
