# 日次ルーチン（A 試験対策 ＋ B 原理理解）

1. `PROGRESS.md` を読み、`README.md` のカリキュラムのうち最初の未完了テーマを選ぶ。
2. `lessons/NN-<slug>.md` を作成する。構成は必ず次のとおり。
   1. **ねらい**（3 行以内）と **試験科目**
   2. **原理編**：核になる原理を、基本法則（保存則・状態方程式など）から導く。
      式ごとに記号の意味・単位・前提を書く。「なぜその式の形になるか」を言葉でも説明する。
   3. **実務とのつながり**：設備・保安・法令でどう使われるか。
   4. **試験編**
      - 計算問題 2 問：数値を入れて解く。解き方の手順も書く。
      - 正誤問題 3 問：試験によくある「誤っているものはどれか」形式。
      - 解答と解説は `<details>` で折りたたむ。解説では、どの原理から判断できるかを示す。
   5. **よくある誤解・ひっかけ**（2〜3 個）
   6. **参考文献**：本文の主張ごとに出典を付け、すべて機能するハイパーリンクにする。
      WebSearch / WebFetch で実在を確認した URL だけを使う。公的機関・学会・事業者の一次資料を優先する。
3. `PROGRESS.md` に行を追加する（番号・テーマ・日付・ノートへのリンク）。
4. コミットしてプッシュする。
