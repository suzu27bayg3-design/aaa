  正式な範囲はガス事業法施行規則と試験実施機関の公示で確認すること。

## 方針

- **基礎理論・ガス技術（01〜26）**：原理の理解に絞る。試験対策はしない。
  核になる式・法則を基本法則から導き、計算例と理解確認の問題で使えるようにする。
- **法令トラック：高圧ガス製造保安責任者（甲種機械）の法令**：試験対策として学ぶ。
  過去問の論点を、本試験と同じ形式（イ・ロ・ハの組合せを選ぶ）の演習セットにする。置き場所は `koatsu-koukikai/`。
- **進め方**：技術トラック（01〜26）を毎日 1 本書く。法令トラックは全 16 セットを作成済み。
