# ガス技術 日次学習ノート

毎日、その日に使い切れなかったトークンで 1 テーマずつ学ぶためのノート集。
各レッスンは「基礎原理 → 応用・実務 → 確認問題 → 参考文献（リンク付き）」の順で書く。

- 進捗: [`PROGRESS.md`](PROGRESS.md)
- 毎日の作業手順: [`ROUTINE.md`](ROUTINE.md)
- 分野分けの目安: ガス主任技術者試験（科目「法令」「基礎理論」「ガス技術（製造・供給・消費）」）
  — 試験の構成は [ガス主任技術者試験 - Wikibooks](https://ja.wikibooks.org/wiki/%E3%82%AC%E3%82%B9%E4%B8%BB%E4%BB%BB%E6%8A%80%E8%A1%93%E8%80%85%E8%A9%A6%E9%A8%93) を参照。
  正式な範囲はガス事業法施行規則と試験実施機関の公示で確認すること。

## 方針

- **基礎理論・ガス技術（01〜26）**：原理の理解に絞る。試験対策はしない。
  核になる式・法則を基本法則から導き、計算例と理解確認の問題で使えるようにする。
- **法令（27〜34）**：試験対策として学ぶ。条文の趣旨を押さえたうえで、
  ガス主任技術者試験の形式に近い正誤問題を中心に演習する。
- **2 本を同時に進める**：毎日、技術トラック（01〜26）から 1 本、法令トラック（27〜34）から 1 本を書く。
  法令トラックは先に終わるので、その後は法令の演習編（L-01, L-02, …）を毎日 1 本続ける。
