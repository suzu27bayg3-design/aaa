## (a) デザイン方針

### コンセプト
「決算短信を、静かに読む」。金融の解説動画として、派手な効果は使わない。浜松ホトニクスの「光」を、**暗いインク色の地に灯る琥珀色の一点**として、表紙・アクセントスライド・暗いスライドにだけ置く。中身のスライドは温かい紙色の地に、インク色の文字と、青(増加・注目)/橙(減少)の2色だけでデータを語る。**1チャートに1メッセージ**。見出しはその主張ではなく話題を示し、主張はチャートと話者メモ(ナレーション)が担う。

### パレット(hex。`deck.css` の `:root` に定義済み)
| 役割 | 変数 | hex | 用途とコントラスト |
|---|---|---|---|
| 暗 | `--ink` | `#111B2E` | 文字、暗い背景(表紙・最後) |
| 明 | `--paper` | `#F4F2ED` | 通常の背景。インク文字で 16:1 |
| 明の2トーン目 | `--paper-2` | `#E8E4DB` | 強調文スライド(`.s-alt`)、表の見出し行、札 |
| カード面 | `--card` | `#FBFAF7` | カード、タイル |
| 罫線 | `--line` | `#D3CDC1` | ヘアライン |
| 補足文字 | `--muted` | `#4F5A6B` | 紙色の上で 6.5:1、paper-2 の上で 5.7:1 |
| 補足文字(暗地) | `--muted-dark` | `#A9B4C4` | インク地の上で 8:1 |
| アクセント1(光) | `--amber` | `#F2A93B` | 暗地の上の強調(8.4:1)、アクセントスライドの背景(その上はインク文字のみ)。**明るい地の上で文字や細い線に使わない**(1.8:1) |
| アクセント2 | `--blue` | `#1F5FA8` | 明るい地の上の強調文字・増加・注目の棒(5.9:1) |
| 減少(図形) | `--down` | `#C8611E` | 減少の棒(3.6:1) |
| 減少(文字) | `--down-text` | `#A8441A` | 減少の数字(5.3:1) |
| 比較対象(図形) | `--bar` | `#6F7F96` | 比べる相手の棒(3.6:1) |

- 純白・純黒は使わない。増加と減少は色相(青/橙)だけでなく明るさも違う(青の方が暗い)。さらに数字に必ず「+」「−」を付けるので色だけに頼らない。
- 費用の増加(販管費+289など)は利益を減らす側なので **橙(down)** で塗る。ウォーターフォールの販管費の棒と、販管費内訳の棒は同じ橙にそろえる。

### 背景の使い分け
- `.s-dark`(インク地): 表紙 `cover` と最後 `closing` の2枚だけ。
- `.s-accent`(琥珀地): デッキで1枚だけ。`hook-profit`(営業利益 567→272)。
- `.s-alt`(paper-2 地、見出しなし・中央寄せ): 強調文の `moat-leverage` の1枚だけ。
- それ以外は全部 `.s-content`(紙色)。

### 書体(`deck.json` の faces に登録済み。これ以外は使わない)
- **Noto Sans JP**(400/500/700): 日本語のすべて。`body` と `section` に設定済みなので、指定しなければこれになる。
- **Inter**(400/600/700): 数字だけ(`.bignum` `.num` `.val` `.step-num`、ページ番号)。**Inter のクラスの要素に日本語を入れない**(フォールバックで別書体になる)。「億円」「%」以外の単位や日本語は、隣の `<p class="unit">` に分ける。「%」「倍」はどちらでもよいが、「倍」は日本語なので `.unit` に分ける。

### 余白と見出しの位置
- すべてのスライド(表紙を含む)の `padding` は `128px 128px 160px`(`section` に設定済み)。中身の領域は x 128〜1792、y 128〜920。
- コンテンツスライドは最初の子を必ず `.head`(`p.eyebrow` + `h2.title`)にする。見出しは常に上の余白(y=128)から始まり、全コンテンツスライドで同じ高さ。`.head` の高さは約99px(24px×1.2 + 12 + 48px×1.2)。その下に `gap:48px`、本文 `.body` は **y≈275〜920 の約645px** に収める。
- `.body` は `flex:1` で下まで伸びる。中身が少ないときは `.body-spread`(上下に散らす)か `.body-center` を使う。`section` 自体に `justify-content:center` を付けない(見出しが動く)。

### フッター
- `p.footer`(左、出典・基準日)と、ページ番号(右、`section::after` の counter。`.s-content` `.s-alt` `.s-accent` で自動表示、`.s-dark` では非表示)。どちらも `bottom:64px` の24px行1本。
- フッターの文は **1行・全角換算56字以内**(幅1400px、`white-space:nowrap`)。短信のURLは概要欄に任せ、スライドには書かない。
- 標準のフッター文(各スライドの指定に従う):
  - F1: `出典: 浜松ホトニクス 2026年9月期決算短信(2026年11月10日公表)`
  - F2: `出典: 浜松ホトニクス 決算短信(2024年9月期、2026年9月期)` (3年比較。2023年9月期の値は2024年9月期短信の前期欄)
  - F3: `出典: 浜松ホトニクス 決算短信(2024年9月期〜2026年9月期)`
  - F4: `株価: Yahoo Finance(2026年11月27日終値)/決算: 2026年11月10日公表の決算短信`
  - F5: `決算: 2026年11月10日公表の決算短信/株価: 2026年11月27日終値(Yahoo Finance)`(表紙・最後)

### 動き
- 到着時に下から浮かぶ `.enter`、ふわっと出る `.fade`、遅延 `.d1`〜`.d4`(150ms刻み)。1スライドの全要素が1秒以内に出そろうように、`.d4` までにとどめる。ループ・点滅・クリック送り(fragment)は使わない(動画収録のため)。
- スライドを離れるときの遷移は全スライド `data-transition="fade"`。

### 数字の表記
- 年度は「2026年9月期」と書く(FY表記は使わない)。グラフの軸ラベルも同じ。
- 億円は **百万円の値を四捨五入**(台本の方針。2,434億円、162億円、181億円)。小数を出すのは台本が出しているもの(−5.6億円)だけ。
- 符号: 増加は「+」、減少は「−」(U+2212 のマイナス記号。ハイフン「-」や全角「ー」ではない)。
- 桁区切りのカンマを入れる(2,434、2,007.5)。単位は数字のすぐ後(「億円」「%」「倍」「円」)。
- 「約」は Inter の数字の `<p>` に入れない(Inter に日本語を入れないため)。大きな数字・タイル・チャート・表の値には「約」を付けず、四捨五入であることを `.note` で示す。ラベル・本文・札(Noto Sans JP の `<p>`)の中では、台本どおり「約」を付けてよい(例: 札「3年前を約10%上回る」)。

## (d) 日本語組版の注意(重要)

- スライドは **半角スペースでのみ折り返す**。日本語には単語区切りがないので、折り返しの挙動に頼らない。**行は `<br>` で意図的に切り**、各行がその箱の幅に収まるよう字数を数えて設計する。
- 目安: **全角1文字 ≒ font-size px**。数字・英字(半角)は約 0.6 × font-size。
  - 中身の幅 1664px で: 80px → 20字、48px → 34字、32px → 52字、24px → 69字。
  - カード・箱の内幅 = 箱の幅 − 左右の padding(`.card` は 80px、`.step` は 64px、`.tile` は 80px)。例: `.grid-4` のカード(幅 392px)は内幅 312px → 32px で9字、48px で6字。`.grid-3`(幅 533px)は内幅 453px → 32px で14字、24px で18字。`.grid-2`(幅 816px)は内幅 736px → 32px で23字。
- 改行は文節の切れ目で(「光が「光電面」と<br>呼ばれる膜に当たる」)。助詞だけ・句読点だけの行を作らない。
- 日本語の文の中に半角スペースを入れない(意図しない折り返し点になる)。逆に、表紙のアイブロウのように意図して区切るときだけ使う。
- **最小フォント 24px**(フッター・軸・注記を含む)。タイトル(`h2.title`)は **1行・全角20字以内**(48px)。強調文・表紙の `h1.display` は 2行まで(1行 20字以内)。
- 本文は短く。1スライドの文字(話者メモを除く)は目安で 150字以内。文は表・カード・大きな数字・SVGチャートに置き換える。説明はナレーション(話者メモ)が担う。
- 長い注記(`.note`)は2行まで。それ以上は分割するか、フッターに回すか、削る。
- 数字と単位は `.num-row` で別の `<p>` に分け、下揃え(baseline)で並べる。
- 句読点は「、」「。」。括弧とスラッシュは、1つのデッキの中で同じ文字にそろえる(作成済みの cover・見本と同じ文字。迷ったらそこからコピーする)。マイナスは「−」(U+2212)。

## (e) 構造上のルール

1. 1ファイル=1つの `<section id="ファイル名と同じid">`。その前後に何も書かない。`<html>` `<head>` `<body>` `<title>` `<style>` `<link>` `<script>` は禁止。
2. section に背景クラスを1つ必ず付ける(`s-content` `s-alt` `s-accent` `s-dark` のどれか)。`data-transition="fade"` を付ける。
3. **最後の子は `<aside>`(話者メモ、プレーンテキスト、4,000字以内)**。台本の文章をそのまま入れる(上の各スライドの指定)。
4. 画像(`<img>`)は使わない。data: URI・外部URLは禁止。図はすべて HTML の箱か `<svg>`。
5. SVG: 1つ52KB以内、`width`/`height` を `viewBox` と同じにする、**`<text>` を書かない**(ラベルは `<p>` をホストの中に絶対配置で重ねる)、`<script>`・`on*=`・`foreignObject`・URL参照なし(`url(#id)` の同一SVG内参照は可)、`<style>` は使わず属性で塗る、`aria-label` で中身を説明する。SVG はホストの最初の子に置く(後に置くとラベルを覆う)。
6. 1つの `<div>` の中の絶対配置要素は **24個以内**。1スライド **200要素以内**。`<div>` の入れ子は **15階層以内**(目安は5階層まで)。
7. **フッターは `p.footer` の1本だけ**(`bottom:64px` の24px行。`deck.css` 定義済み)。フッターのあるスライドは padding `128px 128px 160px`(`section` に定義済み。変えない)。y 920 より下には、フッターとページ番号以外を置かない。絶対配置の要素も `top+height ≤ 920`。
8. **見出しの位置は全コンテンツスライド(`.s-content`、および theme-check)で同じ高さ**: 最初の子を `.head` にし、`section` に `justify-content` を付けない。中身の上下の配置は `.body` 側(`.body-spread` / `.body-center`)で行う。
9. インラインの `style` に書いてよいのは **座標と寸法と配置**(`left` `top` `width` `height` `gap` `justify-content` など)だけ。色・書体・文字サイズはクラスで(`deck.css` の一覧から選ぶ)。`#id` のCSSは書けない(`<style>` 禁止)。
10. テキストを持つ要素には必ずクラスを付ける(`.card p` のような子孫セレクタは定義していないので、クラスのない `<p>` は 32px にならない。`p` の既定は 32px/400 だが、サイズは必ずクラスで指定する)。見出しタグ(h1〜h3)は文字サイズを継承しないので、必ず `.display` `.title` `.card-title` `.card-title-lg` のどれかを付ける。
11. 絶対配置の文字 `<p>` には `width` を必ず付ける。
12. 表: `<table class="tbl">`、1行目を `<tr class="tbl-head">` の `<th>`。セルに `<b>` や2行目以降の `<th>` は使わない。列幅は1行目のセルに `width:%`。数値の列は `class="right"`。1行あたり 2.1×32px≈67px、2行のセルは2倍で高さを見積もる。
13. 矢印は `<x-shape kind="arrow-right" class="arrow"></x-shape>`(64×32)。中に何も書かない。
14. 棒グラフを div で描くとき(layout.md の型): 縦棒は、高さ固定の枠に `align-items:flex-end` で並べ、値は棒の上、年度は枠の下の別の行。全部の棒が同じゼロ・同じスケール。横棒は `.track`(position:relative、高さ56px)の中に `.zero` と棒を `.pin` で置く。
15. 完成したら、自分のスライドごとに次を確かめる: (1) 数字がこの仕様書・照合済みデータと一致、(2) 各行の字数が箱の幅に収まる、(3) 本文の下端が y 920 以内(見出し約99px+48px、本文約645px)、(4) 絶対配置の数、(5) `<aside>` が最後の子で台本どおり。

## 見本の使い方
- `ex-bignum.html`: 大きな数字型。見出し → `.body.body-center` → 数字の行(`.stat` ×2+矢印)→ 札 → 注記 → フッター → aside。hook-sales はこれを写して id を変える。perf-gpm、fin-return、fin-policy の数字部分もこの型。
- `ex-chart.html`: SVGチャート+注記型。`.chart` ホストの最初の子に SVG(棒と線だけ、`<text>` なし)、その上に `p.pin` のラベルを座標で重ねる。右の列にカードと注記。perf-trend はこれを写して id を変える。perf-waterfall もこの型(座標は上記)。
- 見本のコメント(`<!-- -->`)のように、ホストの座標の根拠(ゼロの位置、スケール、棒の中心)をHTMLコメントで1行残すと、検証者が数字と高さの対応を確かめられる。
